# SmartSpace — Demo room

الغرفة التجريبية مقاسها **5 × 4 × 2.60 متر**، ومفتوحة من الأمام وبدون سقف لتسهيل عرضها في Studio.

## الملفات

- **SmartSpace_Demo_Room.glb**: الغرفة كاملة مع الأثاث. كل قطعة تحت عقدة مستقلة باسم ثابت يمكن تحريكها مع جميع أجزائها.
- **Room_Shell.glb**: أرضية وحائطان وشباك توضيحي بدون أثاث.
- **Sofa_01.glb / Coffee_Table_01.glb / Bookshelf_01.glb / Desk_01.glb / Chair_01.glb / Rug_01.glb**: كل قطعة في ملف مستقل، وأصلها عند منتصف القطعة على مستوى الأرض.
- **room_layout.json**: مقاسات الغرفة وأسماء القطع ومواضعها الأصلية، لتسجيلها في الداتابيز لاحقًا.
- **room_preview.png**: معاينة مرسومة من نفس الأشكال والأبعاد المستخدمة في ملفات GLB.

الوحدات بالمتر، المحور Y لأعلى، والدوران بالراديان. ملفات القطع الفردية تُركّب في مواضع `position` من JSON للوصول لنفس توزيع الغرفة الكاملة. العقد البنيوية من نوع `structure`، والأثاث `furniture` مع معرف `smartspace_id`.

النموذج مبسط وتجريبي، وليس مسحًا لغرفتك. لا يحتاج صورًا أو خامات خارجية، ولا يتضمن حركات أو إضاءة مخبوزة. النافذة سطح ملون توضيحي وليست فتحة معمارية حقيقية.

## نعمل إيه دلوقتي؟

فك ضغط المجلد واحتفظ به. ملف البداية هو **SmartSpace_Demo_Room.glb**. شاشة الاستيراد وStudio في الموقع لم تُنفذا بعد؛ الملفات دي جاهزة لاستخدامها عند بناء الخطوة دي.

عند ربطها بقاعدة البيانات، نستورد Room_Shell كغرفة، وكل قطعة كعنصر مستقل. استيراد الملف الكامل وحده في دالة قاعدة البيانات الحالية يحفظ الملف فقط؛ لا يستخرج العناصر تلقائيًا.
